Lámina conceptual con contenido ficticio. Las piezas de esta página describen la experiencia y sus responsabilidades visibles.

## 01 / Recursos

Selección y comprobación de audio, portadas y material de salida.

**En el recorrido:** Seleccionar recursos.

**Responsabilidad relacionada:** Interfaz de producción.

## 02 / Conversión

Preparación de vídeo a partir del material seleccionado.

**En el recorrido:** Preparar una pieza.

**Responsabilidad relacionada:** Colas y operaciones.

## 03 / Cola de trabajo

Seguimiento de estados y progreso de cada operación.

**En el recorrido:** Revisar la cola.

**Responsabilidad relacionada:** Conversión audiovisual.

## 04 / Publicación

Coordinación del paso de una pieza preparada a una publicación autorizada.

**En el recorrido:** Autorizar la publicación.

**Responsabilidad relacionada:** Integraciones privadas.

## Relación entre las piezas

Seleccionar recursos → Preparar una pieza → Revisar la cola → Autorizar la publicación.

El recorrido permite discutir jerarquía, navegación y continuidad. La representación se simplifica a propósito y no publica los contratos internos de implementación.
