## Qué enseña esta publicación

Guion ilustrado de una cola con pistas ficticias. No se sube contenido a ninguna cuenta externa.

El flujo público comunica la experiencia prevista y documentada; no distribuye ejecutables ni código de integración.

## Guion del caso de estudio

Este guion sirve para explicar el recorrido documentado y preparar una demostración controlada. No afirma que se haya ejecutado completo durante esta publicación.

1. **Seleccionar recursos.** Observar: Selección y comprobación de audio, portadas y material de salida.
2. **Preparar una pieza.** Observar: Preparación de vídeo a partir del material seleccionado.
3. **Revisar la cola.** Observar: Seguimiento de estados y progreso de cada operación.
4. **Autorizar la publicación.** Observar: Coordinación del paso de una pieza preparada a una publicación autorizada.
